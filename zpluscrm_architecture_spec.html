2. System Architecture & Synchronization Model

The system uses a Local-First, Cloud-Synced architecture to eliminate loading spinners while ensuring multi-device persistence.

┌─────────────────────────────────────────────────────────────────────────────┐ │ FRONTEND LAYER │ │ Next.js 16 (App Router + Turbopack) | React 19 | TypeScript 5.x │ │ Vanilla CSS Design System Tokens (globals.css) | Lucide React | Recharts │ └──────────────────────────────────────┬──────────────────────────────────────┘ │ ┌──────────────────────────────────────┴──────────────────────────────────────┐ │ STATE & SYNCHRONIZATION LAYER │ │ Zustand 5.x (store.ts) — Local-First Memory Store │ │ Business Key Deduplication Engine (`deduplicateItems`) │ └──────────────────────────────────────┬──────────────────────────────────────┘ │ ┌──────────────────────────────────────┴──────────────────────────────────────┐ │ DATABASE & CLOUD BACKEND │ │ Supabase PostgreSQL Cloud (dwtsntjkysxlqluouhbr.supabase.co) │ │ Row-Level Security (RLS) + Multi-Tenant `user_id` Text Scoping │ └─────────────────────────────────────────────────────────────────────────────┘

Synchronization Pattern & Flow:

  1. UI Mutation: When a user performs an action (e.g. adding a client or saving an invoice), the UI component immediately updates the local Zustand store state (0ms latency).
  2. LocalStorage Backup: State is serialized to browser LocalStorage as an instant offline backup.
  3. Silent Cloud Push: An asynchronous, non-blocking network request is dispatched to Supabase via supabaseData.ts to update the cloud PostgreSQL database.
  4. Multi-Device Fetch: When logging in on a new device, fetchAllCRMData(userId) fetches all 13 tables in a single Promise.all execution.

4. Core Technical Algorithms & Code Logic

A. Business Key Deduplication Engine (src/lib/store.ts)

function deduplicateItems<T extends { id: string }>(
  items: T[],
  getKey?: (item: T) => string
): { unique: T[]; duplicateIds: string[] } {
  const seenIds = new Set<string>();
  const seenKeys = new Set<string>();
  const unique: T[] = [];
  const duplicateIds: string[] = [];

  items.forEach((item) => {
    if (!item || !item.id) return;
    if (seenIds.has(item.id)) { duplicateIds.push(item.id); return; }
    if (getKey) {
      const key = getKey(item);
      if (key && seenKeys.has(key)) { duplicateIds.push(item.id); return; }
      if (key) seenKeys.add(key);
    }
    seenIds.add(item.id);
    unique.push(item);
  });

  return { unique, duplicateIds };
}
